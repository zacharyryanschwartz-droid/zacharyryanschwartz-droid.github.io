# Market Plot — playable prototype

Early playable prototype of **Market Plot**, a cozy invent-and-sell farming game: **Think It, Sell It!**
Type any idea in the Workshop, grow or cook it, and sell it to customers who react to what you made.

- Password-protected playtest build (client-side gate).
- **Demo AI mode:** no AI server is connected. Inventions, customer reactions and the Bazaar run on built-in offline
  stubs and canned sample data in your browser. Progress saves to this device (localStorage).
- Built 2026-10-25 from the prototype source; republished on every new build.
